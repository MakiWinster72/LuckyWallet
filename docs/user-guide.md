# 使用手册

## 登录

打开 LuckyWallet 后，在登录页输入用户名和密码。开发环境示例账号：

| 用户名 | 密码 | 角色 |
| --- | --- | --- |
| `MakiWinster` | `maki1234` | 管理员 |
| `Ula` | `ula12345` | 普通用户 |
| `Anna` | `anna1234` | 普通用户 |

示例密码仅用于本地开发，部署到生产环境后应立即修改或禁用示例账号。

![登录页面](/myDocs/Picture/登录页面.png)

## 首页概览

登录后可以查看：

- 当前月份的共同支出
- 月度预算及使用进度
- 待结算金额
- 最近账单
- 支出分类统计

首页的月份筛选会影响统计卡片和账单列表显示范围。

![首页概览](/docs/Picture/总览.png)

## 查看账单

账单列表会显示账单标题、金额、付款人、日期、分类和参与成员。可以使用搜索和筛选功能查找账单。

账单金额代表整笔共同支出；参与成员的分摊金额代表每个人应承担的部分。

点击查看更多可以跳转到账单页面。

![账单页面](/docs/Picture/账单.png)

## 新增账单

1. 打开新增账单页面。
2. 填写标题、金额、付款人、日期和分类。
3. 选择参与成员。
4. 查看平均分摊预览。
5. 提交保存。

付款人可以同时作为参与成员。系统会校验参与成员的分摊总额是否等于账单金额。

![新增账单页面](/docs/Picture/新增账单页面.png)

## 预算

预算页面显示当前家庭的月度预算和使用情况。管理员可以调整月度预算；预算必须为正数。

预算统计按照账单日期归入对应月份，不按照创建时间归类。

## 成员和权限

- 普通用户可以登录、查看账单并参与共同记账。
- 管理员可以管理成员、调整预算和执行管理员操作。
- 被停用的用户不能正常登录。

## 个人资料

在个人资料页面可以查看和修改昵称、头像等信息。修改后刷新页面即可看到更新结果。

![个人资料页面](/docs/Picture/个人中心.png)

## 结算理解

每笔账单记录两类信息：

- 付款人：实际先支付整笔金额的人；
- 参与人：需要承担分摊金额的人。

结算时应根据付款人与参与人的净额关系进行转账。系统展示的是记账依据，不会自动发起银行或支付平台转账。

## 常见问题

### 登录失败

确认后端已经启动、数据库连接正常，并检查用户名大小写。重新初始化数据库后，示例用户密码以数据库 seed 脚本为准。

### 页面无法加载数据

确认后端运行在 `http://127.0.0.1:8000`，并检查后端的 `DATABASE_URL`、`JWT_SECRET` 和 `FRONTEND_ORIGIN` 配置。

### 重置本地数据

在 `sql` 目录执行：

```bash
mysql -u root -p luckywallet_dev < 004_reset_database.sql
```

该操作会删除本地数据库中的已有账单、用户和日志，请勿在生产环境执行。
